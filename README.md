<div align="left">
    <p>
        <strong>host-lang</strong> is the single doorway between programs and the platform. Host functions (printing, files, network, environment, time) are registered with typed signatures; programs call them by name; and every call passes a capability-based permission gate, so a sandboxed program can do exactly what it was granted and nothing else.
    </p>
    <br>
    <hr>
    <p>
        <strong>MSRV is 1.85+</strong> (Rust 2024 edition).
    </p>
    <blockquote>
        <strong>Status: pre-1.0, in active development.</strong> The public API is being designed across the 0.x series and frozen at <code>1.0.0</code>. See <a href="./CHANGELOG.md"><code>CHANGELOG.md</code></a>.
    </blockquote>
</div>

## Installation

```toml
[dependencies]
host-lang = "0.1"
```
